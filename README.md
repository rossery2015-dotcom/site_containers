# Проекты — карточки новостроек

Современное веб-приложение для отображения карточек новостроек, построенное на Next.js 14 с использованием App Router.

## Особенности

- 🚀 **Next.js 14** с App Router
- ⚡ **Оптимизированные изображения** с Next.js Image
- 📱 **Адаптивный дизайн** для всех устройств
- 🎨 **CSS модули** для изолированных стилей
- 🔧 **Компонентная архитектура** для переиспользования
- 🌙 **Темная тема** с градиентным фоном
- ✨ **Интерактивные элементы** с hover-эффектами

## Структура проекта

```
├── app/                    # App Router (Next.js 14)
│   ├── layout.js          # Корневой layout
│   ├── page.js            # Главная страница
│   └── globals.css        # Глобальные стили
├── components/            # React компоненты
│   ├── icons/             # SVG иконки
│   ├── Badge.js           # Компонент бейджа
│   ├── MetaChip.js        # Компонент мета-чипа
│   ├── Popover.js         # Компонент всплывающего окна
│   ├── ProjectCard.js     # Основной компонент карточки
│   └── *.module.css       # CSS модули для компонентов
├── data/                  # Данные приложения
│   └── projects.js        # Массив проектов
├── styles/                # Глобальные стили
│   └── globals.css        # CSS переменные и базовые стили
└── package.json           # Зависимости проекта
```

## Установка и запуск

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Запустите проект в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Откройте браузер:**
   Перейдите по адресу [http://localhost:3000](http://localhost:3000)

## Доступные команды

- `npm run dev` - Запуск в режиме разработки
- `npm run build` - Сборка для продакшена
- `npm run start` - Запуск продакшен сборки
- `npm run lint` - Проверка кода линтером

## Технологии

- **Next.js 14** - React фреймворк
- **React 18** - UI библиотека
- **CSS Modules** - Изолированные стили
- **Google Fonts** - Шрифт Inter
- **Unsplash** - Изображения проектов

## Компоненты

### ProjectCard
Основной компонент карточки проекта с:
- Изображением и бейджами
- Мета-информацией (локация, время)
- Ценой
- Всплывающим окном с деталями

### Badge
Компонент бейджа с поддержкой:
- Разных типов (default, muted, accent)
- Иконок
- Адаптивного дизайна

### MetaChip
Компонент для отображения мета-информации:
- Локация с иконкой
- Время до центра с иконкой

### Popover
Всплывающее окно с детальной информацией:
- Список квартир
- Ссылка на подробности
- Информация об отделке

## Адаптивность

Проект полностью адаптивен:
- **Мобильные устройства** (< 760px): 1 колонка
- **Планшеты** (760px - 1120px): 2 колонки  
- **Десктоп** (> 1120px): 3 колонки

## Производительность

- Оптимизированные изображения с Next.js Image
- Ленивая загрузка изображений
- Приоритетная загрузка первых 3 изображений
- Оптимизированные шрифты Google Fonts
- CSS модули для минимизации CSS
