## 📋 Что нужно сделать для запуска:

### 1. Установить Node.js (если не установлен)
```bash
# Проверить версию Node.js
node --version

# Если Node.js не установлен, скачайте с https://nodejs.org/
# Или установите через Homebrew (macOS):
brew install node
```

### 2. Установить зависимости
```bash
# Перейти в папку проекта
cd "/Users/Kostiantyn/Desktop/project cursor"

# Установить зависимости
npm install
```

### 3. Запустить проект
```bash
# Запуск в режиме разработки
npm run dev

# Или альтернативные команды:
yarn dev
pnpm dev
```

### 4. Открыть в браузере
Перейдите по адресу: http://localhost:3000

## 🔧 Если возникают ошибки:

### Ошибка "Module not found"
```bash
# Очистить кэш и переустановить
rm -rf node_modules package-lock.json
npm install
```

### Ошибка "Port 3000 is already in use"
```bash
# Запустить на другом порту
npm run dev -- -p 3001
```

### Ошибка с CSS модулями
Убедитесь, что все файлы `.module.css` находятся в правильных папках.
